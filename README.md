# AI 辦公室

一個可以用手機看的 3D 辦公大樓頁面，即時顯示各個 AI 助理（bot）目前在做什麼。

- 3 層樓：3F Nori；2F Meron、Yuzu、Goya、Ichigo；1F 阿卡拉專案經理。
- 每位 bot 坐在自己的座位，頭上有名牌與狀態泡泡（工作中／完成／待命／等待用戶／錯誤）、目前步驟。
- 下方抽屜（桌機為右側面板）：各 bot 狀態與最後更新時間、用量概況、各 bot 排程、最近事件。
- 單指拖曳旋轉、雙指縮放／平移，點名牌或人物可看詳情；「重設視角」回到預設畫面。
- 裝置不支援 WebGL 時，自動改成清單檢視，資料一樣完整。
- **工作中**的 bot 坐在自己的辦公桌打字；其他狀態（待命、完成、等待用戶、錯誤、超過 12 小時未更新）會走到同一層的**休息區**坐下，狀態動畫照常顯示。狀態改變時會走過去（約 1.5 秒），剛開頁面時直接就位。
- **左側樓梯、右側玻璃電梯**連接 1F–3F。**送資料動畫**：bot 拿著文件走樓梯或搭電梯到對方的樓層與座位，交給對方後走回座位。
  - FEED 狀態的步驟文字出現「交／交給／交付給／交件給／交辦／轉交給／回報給／通知／送給／傳給／派給」後面**緊接著**某位 bot 名字（中間只能有空白，例如「交 Nori 驗收」「通知 Yuzu」）時，會由該 bot 送文件給那一位；同一句提到多位時取最先出現的。狀態為「完成」且提到交付／交件／回報但沒寫對象時，送給 Nori。描述問題的句子（含「為何／為什麼／原因／是否／有沒有／查修」）不觸發；開頁前的歷史訊息只用來顯示狀態，不會重播送文件。不會改動任何 FEED 格式。
  - 「示範：送資料」從 6 位裡隨機挑一位寄件人，再從其他 5 位平均隨機挑收件人（可能同樓層）。
  - 「狀態」分頁有「示範：送資料」按鈕；瀏覽器主控台也可呼叫 `__aiOfficeDeliver('goya', 'nori', 'stairs')`（第三個參數：`stairs`、`elevator` 或 `auto`）。
- **5 套角色外型**（「外型」分頁切換，記在這台裝置）：標記吉祥物（預設，用 looks 的 shape 做成圓潤的角色本體）、上班族、圓圓機器人、貓咪同事、Q 版太空人。顏色一律跟著 looks 的 color。
- **白天／夜晚**：預設依台北時間自動切換（06:00–18:00 為白天），頁首按鈕可切換「自動／白天／夜晚」並記在這台裝置；網址也可加 `?theme=day` 或 `?theme=night`（放在 `#` 前面）。
- **背景音樂**：右下角喇叭按鈕可開／關，選擇記在這台裝置（localStorage `ai-office:music`）。預設為「開」，但瀏覽器（特別是 iOS）不允許自動播放，所以會在你第一次點擊或觸控頁面時才開始；關掉之後不會自動開始。音量很小，白天較明亮、稍快，夜晚較柔和、較暗，跟著白天／夜晚自動平順切換；分頁切到背景時會淡出暫停。

## 使用方式

在網址最後加上頻道代號：

```
https://rrrdan.github.io/ai-office/#<頻道代號>
```

頻道代號只放在網址的 `#` 後面，不會送到 GitHub，也沒有寫在原始碼裡。沒加代號時，頁面會提示你怎麼加。

## 資料與隱私

- **唯讀**：只用 GET 讀取 `https://ntfy.sh/<頻道代號>` 的訊息（先讀歷史，再用 SSE 即時更新；SSE 失敗時每 15 秒輪詢一次）。不會發送或修改任何訊息。
- 最後已知的狀態（狀態、步驟、時間）、外型選擇與白天夜晚設定會存在這台裝置瀏覽器的 localStorage，開頁時先顯示快取，再和 FEED 歷史合併。ntfy 只保留約 12 小時，所以超過 12 小時沒有新狀態、或這台裝置從沒看過的 bot，會顯示「超過 12 小時未更新」。localStorage 只存在單一裝置：換新裝置第一次打開時看不到更早的狀態。頁面底部可「清除這台裝置的快取」。
- 載入順序：先畫快取 → 立刻讀取 FEED 歷史（`/json?poll=1&since=all`）並畫出清單與卡片 → 再開 SSE（`since=<最後一筆 id>`）；SSE 6 秒內沒連上就先每 15 秒輪詢，連上後自動停止輪詢。3D 場景最後才載入，不會擋住資料。沒有顯示卡（軟體算圖）時 3D 會自動降低更新頻率。
- 手機版的名牌只顯示「樓層＋狀態圓點＋名字」，點一下看詳情；名牌只會在自己那層樓的範圍內左右或上下避讓。
- 沒有追蹤、分析、廣告或外部字型；除了 ntfy 之外不連任何外部服務。
- 所有時間以台北時間（Asia/Taipei，UTC+8）顯示。

## 支援的訊息格式（ntfy `message` 欄位內的 JSON）

| 類型 | 格式 |
|---|---|
| 狀態 | `{"bot": 名稱, "status": "working｜done｜idle｜waiting_user｜error", "step": 文字}` |
| 名冊 | `{"roster": [名稱, ...]}` |
| 外型 | `{"looks": {名稱: {"shape", "color", "accessory"}}}` |
| 分組 | `{"groups": {名稱: 分組}}` |
| 對話連結 | `{"chat": {名稱: 連結}}` |
| 用量 | `{"type": "usage", "total_used_pct", "resets_at", "bots": {名稱: 數字}}` |
| 排程 | `{"routines": {"bot": 名稱, "items": [{"name", "schedule", "next_run"}]}}` |

不認得或格式錯誤的訊息會略過或列為「其他訊息」，不會讓頁面壞掉。

## 檔案

- `index.html`、`style.css`：頁面與樣式（系統字型，無外部資源）
- `app.js`：讀取 FEED、抽屜與清單畫面
- `feed.js`：訊息解析與狀態管理（純邏輯，可在 Node 測試）
- `office3d.js`：3D 大樓、家具、樓梯、電梯、休息區、白天夜晚與送資料動畫（全部用程式產生的低多邊形幾何與畫布貼圖，沒有使用外部模型或圖片）
- `music.js`：背景音樂（Web Audio API 即時合成，沒有任何音訊檔）
- `avatars.js`：5 套角色外型（程序化幾何，未使用任何官方標誌檔或商標素材）
- `vendor/three/`：three.js r170（npm `three@0.170.0`）的 `three.module.min.js` 與 `OrbitControls.js`，MIT 授權，見 `vendor/three/LICENSE`
